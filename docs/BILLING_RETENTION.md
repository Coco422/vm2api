## 长期消费与清理边界

按请求发生时的用户、VM 和时间保存计费摘要，支持按用户跨 VM 查历史消费，也支持按单台 VM 查使用期间的用量。摘要保留模型、Token 和费用。普通访问日志和调试正文按各自期限清理。

更换账号并新建 VM 时，新 VM 独立累计。删除旧 VM 可清理其配置、凭据和运行数据，旧 VM 已产生的消费仍归原用户。后续调整 VM 归属时，账单沿用请求发生时的租户快照。可以采用上游 Key 配额计数重置，前提是历史账单和用户、VM 的消费统计仍可核对。

跟版时可复用上游的统计、归档和日志机制，前提是仍能按用户、VM 和时间统计。上游 `v1.4.145` 清理旧摘要时按订阅账号聚合费用和 Token。定制版长期保留带归属的原始摘要，管理员可另外查订阅账号累计用量。升级与回退须用隔离数据验证超期清理、同一用户换 VM 并删除旧 VM、Key 配额重置和跨租户隔离；切换前后核对历史账单与金额，以及请求时的用户和 VM 归属。
